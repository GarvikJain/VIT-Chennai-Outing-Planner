Algorithm Guide

Hover over technique names above to learn when to use each algorithm

A*: Fast, optimal with good heuristics. Best for single-destination routing.
Dijkstra: Guaranteed optimal. Slower than A* but works without heuristics.
BFS: Finds shortest path by hop count, not cost. Good for small graphs.
DFS: Fast exploration. May find suboptimal paths. Useful for reachability.
Bellman-Ford: Handles negative weights (if any). Slower but robust.
Floyd-Warshall: All-pairs shortest path. Best for multi-destination planning.
